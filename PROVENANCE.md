# Provenance et démarche

Le point de départ pédagogique est l’architecture du projet Sentiment-app, puis l’organisation de l’archive `rag-agent-mainothmn.zip` fournie comme référence par l’utilisateur : un paquet métier, une couche API, une interface HTTP, des scripts de données/évaluation, des tests et une CI.

Le code TicketAssist est une implémentation nouvelle du sujet des tickets, préparée avec assistance IA. Le code, les données PIAF, les performances, les noms de modèles, les clés et les résultats du projet RAG ne sont pas copiés ou attribués au binôme TicketAssist. L’exemple n’est pas inclus dans la livraison.

Les données françaises jointes sont simulées. Les statistiques proviennent des exécutions locales de TicketAssist, sans validation externe. Les noms du binôme sont ceux de la base fournie : Mehdi Benjelloun et Oussama Kamil. Les contributions individuelles et les validations académiques ne sont pas attestées par cette génération.

Les dépendances conservent leurs licences propres. Aucune licence du projet de référence n’a été étendue à ce nouveau code. Le binôme doit définir les droits de diffusion de son projet et obtenir ceux de tout corpus réel ajouté.
